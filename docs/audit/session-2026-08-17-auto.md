(`src/hunter/__main__.py:499`, единственный импорт `tgbot` во всём дереве,
проверено `grep -rn "from .tgbot|from hunter.tgbot|import tgbot" src/ scripts/ gates/`).

(проверено `grep -rn "Bot(|aiogram" src/hunter/*.py | grep -v tgbot` → пусто).

`main` печатает «ОТКАЗ: не задан TELEGRAM_BOT_TOKEN» и возвращает 2, не создавая `Bot`.

`uv run python -c "import os; print(bool(os.environ.get('TELEGRAM_BOT_TOKEN')))"` → **False**
(владелец клал ключи через `setx` — user-level, текущему процессу не видны).
