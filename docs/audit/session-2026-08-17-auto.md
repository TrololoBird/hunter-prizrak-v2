## Гейт доставки (шаг 0.5) — записано ДО первого serve

Отправка в Telegram возможна только из `tgbot.main` (`src/hunter/tgbot.py:1298`),
куда ведёт единственный путь — команда `hunter bot`
(`src/hunter/__main__.py:499`, единственный импорт `tgbot` во всём дереве,
проверено `grep -rn "from .tgbot|from hunter.tgbot|import tgbot" src/ scripts/ gates/`).
`serve`/`run`/`check` модулей aiogram не касаются
(проверено `grep -rn "Bot(|aiogram" src/hunter/*.py | grep -v tgbot` → пусто).

Механизм гейта: `tgbot.py:1301-1304` — без `TELEGRAM_BOT_TOKEN` в окружении
`main` печатает «ОТКАЗ: не задан TELEGRAM_BOT_TOKEN» и возвращает 2, не создавая `Bot`.

Живой замер в ЭТОМ процессе:
`uv run python -c "import os; print(bool(os.environ.get('TELEGRAM_BOT_TOKEN')))"` → **False**
(владелец клал ключи через `setx` — user-level, текущему процессу не видны).
Вывод: в этой среде ни `serve`, ни даже случайный `hunter bot` отправить ничего не могут.
`hunter bot` тем не менее не запускается вовсе (стоп-лист п. 1).
