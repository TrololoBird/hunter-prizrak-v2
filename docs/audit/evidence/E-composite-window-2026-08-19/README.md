# Нулевая сила композита: окно смотрело в прошлое

Разбор по запросу владельца 2026-08-19 («разбери нулевую силу композита»).
Полный текст с таблицами — `docs/audit/session-2026-08-17-auto.md`, раздел
«2026-08-19. Нулевая сила композита».

## Что было

В карточках прогона `last` строк «сила по композиту» 9517; «0.0% композита» — 5376
(56.5%), из них РОВНЫЙ ноль (`зона 0`) — 5278. Гейта, сторожащего композит, в проекте
нет: `grep -n "композит\|vrvp" gates/*.py` пусто.

## Механизм (разбор по шагам, не правдоподобная причина)

`_with_vrvp` брала окно самой ДЛИННОЙ по времени структуры символа. Такая структура
почти всегда старая: её окно кончилось за 6.5 / 44.5 / 126.5 / 126.5 / 51.5 суток до
последнего бара, и у трёх символов из пяти в её ценовой коридор не попадала даже
текущая цена. Зоны уровней лежали вне коридора — ноль по построению.

Класс «внутри коридора, но бинов нет» дал 0 из 9715, то есть ни узкая зона, ни дыра в
гистограмме ни при чём.

## Контроли

1. **Класс достижим.** Подсаженная зона шириной в четверть тика между двумя ценами
   бинов попадает в класс «внутри, но бинов нет» у всех пяти символов — печатается
   «СРАБОТАЛ (срез пуст)». Класс, который не наполняется никогда, ничего не доказывал бы.
2. **Прибор не заперт в нуле.** До правки покрытие зон различалось по символам
   (25.8–58.1%), после — 100% у всех.
3. **Старые числа воспроизводятся.** Тот же зонд по СОХРАНЁННЫМ карточкам печатает
   прежние 5376/5278; пересчёт тех же кадров новым расчётом — 4/0.

## Что стало

| величина | было | стало |
|---|---|---|
| строк «0.0% композита» | 5376 | 4 |
| ровный ноль (`зона 0`) | 5278 | 0 |
| покрытие зон коридором композита | 25.8–58.1% | 100% у всех 5 |

Остаток в 4 строки разобран: зоны 14834, 18535, 24510 и 2.15e7 — не нули, доля меньше
0.05% печаталась форматом `.1f` как «0.0%». Формат исправлен.

Цена по времени: композит вырос со 110 808 бинов до 250 702, полный проход по 1987
уровням BTC 1.43 → 3.29 с при `engine.decide` 111.6 с (+1.7%).

`data/frames` на момент замера. Замер 2026-08-19, ветка `auto/2026-08-17-shift`.
