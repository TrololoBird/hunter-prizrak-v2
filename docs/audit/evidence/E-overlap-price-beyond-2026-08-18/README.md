# Наслоение противоположных зон: дифф повтора §10.6 на пакет смены

**Дефект назван ВЛАДЕЛЬЦЕМ, глазами, по карточке:** «допускаешь НАСЛОЕНИЕ противоположных
зон!». Ни один из 25 гейтов его не видел — прибора, который сверял бы сторону уровня со
стороной цены, в проекте не было вовсе.

## Механизм

Сторона уровня — направление выхода из накопления (`acc.is_long`), и она не менялась
никогда. Статус же оставлял уровень ACTIVE при `BreachKind.OPEN` и `UNRESOLVED` — то есть
ровно тогда, когда цена ушла за структуру и не вернулась. Лонговый уровень ВЫШЕ цены
печатался как действующая поддержка, шортовый ниже цены — как сопротивление; на графике
бота обе стороны рисовались рядом, потому что `zones_for_chart` отбирал ближайшие к цене
зоны, не спрашивая о стороне.

Курс: стр. 43 «Уровень лонг/шорт менятся для нас на противоположный»; стр. 7 — пробой это
«когда цена проходит»; стр. 44 запрещает вход, если цена уже торгуется в зоне.

## Правка

`LevelStatus.price_beyond` — цена по ту сторону ВСЕЙ структуры, по последнему ЗАКРЫТОМУ
бару и по границам базы (`src/hunter/levels.py:963`). Условие ветки стало
`if beyond or first_test_index(...) is not None`: лимитки запрещены, вход только по
подтверждению. Причина удержания названа в `emit.hold_reason`, пометка «цена ЗА структурой
(стр. 43)» встала в строку карточки, встречные зоны убраны из графика бота.

## Числа

Знаменатель — строки уровней в СОХРАНЁННЫХ карточках прогона `last`: 9715
(ASTR 1813, BCH 2021, BTC 1987, ETH 1933, POL 1961).

| величина | значение |
|---|---|
| символов повторено | 5 из 5, изменились ВСЕ |
| строк карточки было → стало | ASTR 12712→12723, BCH 14094→14103, BTC 13944→13953, ETH 13552→13562, POL 13758→13770 |
| строк уровней с пометкой «цена ЗА структурой» | **4428 из 9715 = 45.6%** |
| строк диффа всего | 29795 |

Разбор по состояниям снят отдельным зондом по тексту карточек до правки: не с той стороны
от цены стояли 24.8–34.8% АКТИВНЫХ уровней, 43–51% отработанных, 45–49% флипнутых —
прибор различал состояния, то есть выдать одинаковый ответ он не мог. Пар наслоения
встречных зон среди активных: 418 (ASTR), 385 (BCH). Среди 198 эмитированных сигналов
таких **0**: дефект жил в КАРТЕ, а не в эмиссии.

## ⚠ Чего этот дифф НЕ показывает

Сохранённые карточки прогона `last` построены ДО обеих правок пакета, поэтому дифф
показывает их СУММУ, а не один `price_beyond`. В вырезке это видно прямо: вместе с
пометкой меняется и строка «границы» (0.007264…0.007439 → 0.007239…0.007465) — это
слияние двух сущностей границ и правка сетки профиля. Раздельного диффа по одной правке
здесь нет.
