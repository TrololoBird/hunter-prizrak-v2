# Вторая биржа: что даёт сверка и чего она не даёт — 2026-08-11

Повод — главная слабость конструкции, названная ревизией транспорта: **источник цен
ровно один**. Ошибка Binance, делистинг, бан по IP или региональный отказ означают, что
система слепа целиком, и заметить это нечем: собственные проверки судят о данных по этим
же данным.

Bybit отдаёт бары публично, ключей не требует, а библиотека та же (ccxt) — **новой
боевой зависимости здесь нет**, есть новый источник СВЕРКИ. Разрешение владельца на
открытые источники получено 2026-08-10.

## Замер

```bash
uv run python docs/audit/probes/probe_second_venue_2026-08-11.py
```

Свидетельство: [`evidence/E-090-second-venue/`](evidence/E-090-second-venue/).
Отпечаток: 6 символов вселенной × 2 ТФ (1ч, 4ч) × 200 баров = 2400 сверенных баров,
допуск 0.10·ATR14 ([`tolerance-R-01.md`](tolerance-R-01.md)).

| символ | 1ч выше допуска | 4ч выше допуска | медиана расхождения, % цены |
|---|---|---|---|
| BTC | 0 из 200 | 0 из 200 | 0.005 |
| ETH | 0 из 200 | 0 из 200 | 0.005 |
| BCH | 21 из 200 | 1 из 200 | 0.021–0.023 |
| POL | 2 из 200 | 0 из 200 | 0.014 |
| AEVO | 28 из 200 | 2 из 200 | 0.052–0.104 |
| ASTR | 93 из 200 | 64 из 200 | 0.042–0.079 |

Итого: 211 баров из 2400 (8.79%) расходятся сильнее допуска.

## Что это значит — и чего НЕ значит

**Расхождение растёт с тонкостью инструмента.** У BTC и ETH биржи совпадают полностью,
у ASTR расходится почти половина часовых баров. Это не поломка ни у нас, ни у них: у
тонкого символа цена на разных площадках действительно разная, потому что разная
ликвидность. ASTR — самый тонкий символ вселенной (оборот в 20 000 раз меньше BTC, замер
2026-08-04, докстрока `WS_TRADES_SILENCE_S`).

⚠ **Отсюда НЕ следует, что наши уровни на ASTR неверны.** Уровень строится по СДЕЛКАМ
Binance, и для торговли на Binance он верен по построению. Следует другое, и это стоит
сказать прямо: **уровень тонкого символа — свойство площадки, а не рынка**, и переносить
его на другую биржу нельзя. Для BTC и ETH перенос законен, для ASTR — нет.

**Чего сверка не поймала.** Замороженных рядов (одна цена, нулевой объём — форма
делистинга, замер 2026-08-05) не найдено ни одного. Это ожидаемо: во вселенной проекта
делистнутых символов нет, дефект остаётся латентным. Знаменатель напечатан, чтобы ноль
не читался как «проверка не проводилась».

## Контроли фальсифицируемости — оба пройдены

* **КОНТРОЛЬ 1 (способен ли прибор ответить иначе).** Бары BTC сверены с барами ЧУЖОГО
  символа: медиана расхождения **97.05%** против долей процента у честной пары. Мера
  различает «те же данные» и «другие данные».
* **КОНТРОЛЬ 2 (чувствительна ли мера ко времени).** Ряд второй биржи сдвинут на один
  бар: **2030** расхождений выше допуска против **211** у выровненного, то есть согласие
  рушится. Значит «сошлось» означает именно совпадение по времени, а не «цены похожи
  вообще».

## Что предлагается — и что решает владелец

Сверка **не встроена никуда** и расчёта не касается. Предложение, требующее решения:

1. **Мера доверия к символу в приёмке.** Доля баров, расходящихся со второй биржей, —
   готовый показатель качества данных по символу. Он ничего не запрещает, но делает
   видимым то, что сейчас невидимо: уровни ASTR и уровни BTC стоят разного.
2. **Сторож делистинга.** Замороженный ряд у одной биржи при живом у другой — признак,
   которого наши проверки не дают вовсе (`instrument()` ловит `active=False`, но только
   если биржа сама снимет флаг).

⚠ Чего делать НЕ предлагается: подмешивать чужие бары в расчёт. Правило «один ряд — один
источник» введено после разбора швов (`transport-decision-2026-08-05.md`), и склейка
двух бирж — ровно тот шов, где живут дубликаты и невидимые разрывы.
