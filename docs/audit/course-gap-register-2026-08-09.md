# Реестр «курс велит — системы нет» — 2026-08-09

Единый список правил курса, которые задокументированы находками, но НЕ исполняются
системой. До этого реестра они были рассыпаны по шести документам, и увидеть общий долг
было нельзя. Список собран из `03-course-by-page.md`, `03-course-pictures.md`,
`course-full-2026-08-09.md`, `indicators-conformance-2026-08-09.md`,
`stopvol-projects-2026-08-09.md`, `tv-transfer-2026-08-09.md`.

Числа «страниц с правилом» и находки воспроизводятся чтением перечисленных протоколов;
сами страницы:

```bash
uv run --group tools python -c "import pymupdf; d=pymupdf.open('docs/course/Мини Курс по трейдингу от PrizrakTrade.pdf'); [p.get_pixmap(dpi=140).save(f'docs/course/pages/p{i:02d}.png') for i,p in enumerate(d,1)]"
```

Столбец «цена» — оценка объёма работ ЧТЕНИЕМ кода, не замером. Столбец «решение»:
«владельца» = требует выбора величины/приоритета, которого нет в курсе; «техническое» =
курс определяет правило полностью, нужна только реализация.

## ⚠ Сначала — то, что при сборке реестра оказалось УЖЕ ИСПОЛНЕННЫМ

Проверка каждой строки по ЖИВОМУ коду (а не по датированным протоколам) сняла три
старших пункта — правки аудита 2026-08-07 опередили документы, из которых реестр
собирался. Урок тот же, что у всего проекта: код — не истина о курсе, но протокол — не
истина о коде.

* **М-08 (зона, не ПОК) — исполнено 2026-08-07.** `levels.first_test_index` считает
  касанием заход в зону; прежний критерий ПОК описан в его докстроке как отменённый.
* **М-09 (цена уже в зоне) — исполнено 2026-08-07.** `LevelStatus.price_in_zone`
  считается в `levels.status`, `emit.py:85` блокирует эмиссию с названной причиной и
  цитатой стр. 44.
* **А-02 (слом на младшем ТФ) — исполнено НАПОЛОВИНУ, вторая половина — записанное
  решение владельца.** `engine` проверяет слом младшего ТФ после касания и называет
  результат в карточке; эмиссию слом не порождает, и это названо в докстроке решением
  владельца, а не пробелом (вход по слому — новый путь сигнала).

## Замер цены вопроса №2 (М-15) — сделан 2026-08-09

```bash
uv run python docs/audit/probes/probe_whole_candle_2026-08-09.py
```

Отпечаток данных: 54 прогона, 29 уровней. Исходы первого события: пробоев 12, проколов
10, без захода 3, **UNRESOLVED 4**. Из четырёх UNRESOLVED у **трёх** за уровнем не было
ни одной целой свечи (условие схемы стр. 6 выполнено — вопрос «прокол ли это» стоит; все
три на 5м/15м), у одного целые свечи были (даже схема прокола не видит). Контроль:
разбиение не вырождено — прибор различает случаи. Цена вопроса владельцу: три события
на текущем кэше.

Классика по тому же вопросу (`classics-tolerance-2026-08-09.md`, 8 источников): единого
критерия ложного пробоя нет — школа закрытий (Булковски: пробой только по close;
Эдвардс-Маги) поддерживает РИСУНОК стр. 6, школа таймера (Turtle Soup — same day/+1;
2B Сперандео — в пределах дня для minor) поддерживает ТЕКСТ «1-2 свечами». Кодированные
детекторы строят градацию из обоих. Вывод: текст и рисунок — два НЕЗАВИСИМЫХ условия
одного семейства, а не конкурирующие формулировки; выбор комбинации — владельца.

## Закрытие реестра — 2026-08-09, вторая половина дня

Владелец делегировал решения («решения принимай сам по источникам»); статус строк:

* **№2 (М-15) — ЗАКРЫТА ПРАВКОЙ.** Поздний возврат без единого тела за уровнем — прокол
  (классика закрытий заполняет молчание курса по §0.1); с телом — по-прежнему без
  вердикта. Гейт course_rules переписан с обоснованием, 3 уровня на кадрах сменили
  статус, дифф предъявлен. Коммит 38e2100.
* **№6, №8, №9 — ЗАКРЫТЫ ПРАВКАМИ.** Расширенные дивергенции с допуском Булковски <3%
  (константа `factors.EXTENDED_EQUAL_TOL_PCT`, в полосе равенства приоритет у
  расширенной); RSI за уровнем 70/30 — доп-фактор карточки; контр-тренд несёт
  предусловие стр. 47 словами. Коммит a365c31.
* **№4 — ПЕРВАЯ ПОЛОВИНА ИСПОЛНЕНА ПО ПОСТРОЕНИЮ** (проверено чтением 2026-08-09):
  `pereprior._test_index` ищет тест строго ПОСЛЕ бара подтверждения — тест до
  закрепления сделкой не считается. Вторая половина (ордера от 2-х ПП одним стопом) —
  часть построителя сделки от ПП, слита со строкой 3.
* **№10, №11 — ЗАКРЫТЫ РЕШЕНИЕМ «не реализуется»**, основания внесены в §3.1
  FOUNDATION: трендовые по RSI — опциональная формулировка курса без единого параметра
  с референтом; сглаживание SMA 5 — галка не подтверждена ни снимком, ни текстом.
* **№12 — закрыта ранее** (затравка EMA переведена на TV).
* **№1, №3 (+хвост №4), №5, №7 — решения ПРИНЯТЫ, реализация — отдельный заход.**
  Общая машинерия №1/№5 — детект «накопление, прижатое к уровню/зоне ПП» (закрытая
  структура, чья граница в допуске от уровня); №3 — второй построитель сетапа: вход =
  ближний край зоны ПП по закрытию (конвенция обзора BOS), стоп за хай/лой ретеста
  (стр. 52: одна красная зона на оба ПП) либо базу слома, цель — по маршруту «от ПП до
  ПП» (стр. 49); №7 — якорь VRVP-замены: окно от структуры (рекомендация
  vrvp-visible-range, совпадает с TV Auto Anchored и композитами Далтона), строится на
  `build_tv` после получения Row Size. Каждый — своя правка со своим диффом повтора;
  делать их одной кучей значило бы предъявить владельцу нечитаемый дифф.

## Что реестр НЕ утверждает

Он не говорит, что всё перечисленное НАДО реализовать: №6 упирается в §1, №9 — в §0.
Он говорит, что долг теперь виден в одном месте и у каждой строки есть адрес решения.
