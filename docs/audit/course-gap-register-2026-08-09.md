# Реестр «курс велит — системы нет» — 2026-08-09

Единый список правил курса, которые задокументированы находками, но НЕ исполняются
системой. До этого реестра они были рассыпаны по шести документам, и увидеть общий долг
было нельзя. Список собран из `03-course-by-page.md`, `03-course-pictures.md`,
`course-full-2026-08-09.md`, `indicators-conformance-2026-08-09.md`,
`stopvol-projects-2026-08-09.md`, `tv-transfer-2026-08-09.md`.

Числа «страниц с правилом» и находки воспроизводятся чтением перечисленных протоколов;
сами страницы:

```bash
uv run --group tools python -c "import pymupdf; d=pymupdf.open('docs/course/Мини Курс по трейдингу от PrizrakTrade.pdf'); [p.get_pixmap(dpi=140).save(f'docs/course/pages/p{i:02d}.png') for i,p in enumerate(d,1)]"
```

Столбец «цена» — оценка объёма работ ЧТЕНИЕМ кода, не замером. Столбец «решение»:
«владельца» = требует выбора величины/приоритета, которого нет в курсе; «техническое» =
курс определяет правило полностью, нужна только реализация.

## ⚠ Сначала — то, что при сборке реестра оказалось УЖЕ ИСПОЛНЕННЫМ

Проверка каждой строки по ЖИВОМУ коду (а не по датированным протоколам) сняла три
старших пункта — правки аудита 2026-08-07 опередили документы, из которых реестр
собирался. Урок тот же, что у всего проекта: код — не истина о курсе, но протокол — не
истина о коде.

* **М-08 (зона, не ПОК) — исполнено 2026-08-07.** `levels.first_test_index` считает
  касанием заход в зону; прежний критерий ПОК описан в его докстроке как отменённый.
* **М-09 (цена уже в зоне) — исполнено 2026-08-07.** `LevelStatus.price_in_zone`
  считается в `levels.status`, `emit.py:85` блокирует эмиссию с названной причиной и
  цитатой стр. 44.
* **А-02 (слом на младшем ТФ) — исполнено НАПОЛОВИНУ, вторая половина — записанное
  решение владельца.** `engine` проверяет слом младшего ТФ после касания и называет
  результат в карточке; эмиссию слом не порождает, и это названо в докстроке решением
  владельца, а не пробелом (вход по слому — новый путь сигнала).
