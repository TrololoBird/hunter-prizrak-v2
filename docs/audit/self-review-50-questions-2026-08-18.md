## Команда воспроизведения (§7.3)

Числа леджера в разделе А (сигналы, исходы, состояния) — read-only запросом; путь с
`mode=ro` обязателен, боевой леджер писать запрещено:

```bash
uv run python -c "import sqlite3; c=sqlite3.connect('file:data/ledger.sqlite3?mode=ro', uri=True); print('сигналов', *c.execute('SELECT COUNT(*), SUM(kind='level'), SUM(kind='pp') FROM signals').fetchone()); print('исходов', *c.execute('SELECT COUNT(*) FROM outcomes').fetchone()); print(*c.execute('SELECT kind, COUNT(*) FROM outcomes GROUP BY kind').fetchall()); print(*c.execute('SELECT state, COUNT(*) FROM signals GROUP BY state').fetchall())"
```
