# Канонические величины против опубликованного определения — 2026-08-03

Замечание владельца: «согласие двух реализаций не доказывает, что обе верны… Внешний
референт по §0 — не вторая библиотека, а сама формула».

Верно. Ниже — сверка со **формулой**, а не с библиотекой.

## Источник формулы

J. Welles Wilder Jr., «New Concepts in Technical Trading Systems» (1978), в изложении
<https://en.wikipedia.org/wiki/Average_true_range>:

```
TR_t  = max[ (H_t − L_t), |H_t − C_{t−1}|, |L_t − C_{t−1}| ]
ATR_n = (1/n) · Σ_{i=1..n} TR_i                  — затравка простым средним
ATR_t = ( ATR_{t−1} · (n−1) + TR_t ) / n         — при t > n
```

⚠ Это **вторичное изложение**: книги 1978 года в проекте нет. Если владелец её получит,
сверку надо повторить по первоисточнику.

## Результат

Формула посчитана **скалярным циклом** — без polars, без ta-библиотек — и сверена с тем,
что выдаёт проектный код (`polars_talib`, то есть TA-Lib).

| величина | расхождение с определением | сравнено точек |
|---|---|---|
| **ATR(14)** | **0.000e+00** | 485 |
| **RSI(14)** | **4.324e-16** | 485 |

Совпадение **включая затравку**, а не только на хвосте серии.

## Что это меняет — исправление прошлого отчёта

**Числа 144/193/111 из отчёта о прогреве описывали не то, что я утверждал.**

Я подал их как «сколько баров нужно, чтобы значение стало верным». На самом деле они
мерили, **за сколько баров чужая затравка `pandas-ta` сходится к правильной**. Наше
значение верно с первого бара, на котором определено, — это теперь доказано формулой.

Правильная величина для допуска другая: сколько баров нужно, чтобы значение
**существовало**.

| величина | первое значение на баре | нужно баров |
|---|---|---|
| atr14 | 14 | **15** |
| rsi14 | 14 | **15** |
| macd | 33 | **34** |
| ema200 | 199 | **200** |

Держит эти числа честными гейт `gates/indicator_availability.py`: если библиотека сменит
конвенцию затравки, требование поедет и гейт это покажет.
