## Отдельно: фильтр незакрытой свечи действительно работает

Ноль незакрытых баров сам по себе ничего не доказывает — гейт, который ни разу не
сработал, неотличим от гейта, который сработать не может. Прямой замер того, что
фильтр отсекает:

| | |
|---|---|
| обновлений от WS за 330 с (BTC, 5m) | 673 |
| **отсечено как незакрытые** | **672 (99.9%)** |
| прошло как закрытые | 1 (ровно один бар — верно для 5m за 330 с) |

Без фильтра в систему пошли бы 672 снимка формирующейся свечи, выданные за закрытые.

```bash
uv run python docs/audit/probes/probe_unclosed_filter.py
```

Признак закрытости — «биржевое время дошло до правой границы бара», а **не** «отбросить
последний элемент кэша»: последний элемент бывает и закрытым, и тогда отбрасывание
подало бы позапрошлый бар со свежей меткой.

- **Прогон длился 400 секунд.** Обрыв соединения, переподключение, делистинг символа,

  неликвидные символы вселенной проверялись на том же горизонте, что BTC.
- **Данные сверялись с Binance же.** Ошибку самой биржи такой сверкой не поймать.
