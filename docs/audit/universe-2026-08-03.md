# Вселенная — замер 2026-08-03

FOUNDATION.md §5: «закреплённый набор символов, задаваемый оператором»,
«Не-крипто инструменты (XAU, XAG, PAXG) исключены».

Результат: `config/universe.toml`, 27 символов. **Ждёт подтверждения владельца.**

## Правило отбора

    вселенная = символы корпуса ∪ топ-12 по суточному обороту, только крипто-бессрочные

## Опровергнутое ожидание: «топ по обороту» — это не крипто

Первый прогон отбирал по обороту без фильтра на тип инструмента. В топ-12 попали:
**SNDK, SKHYNIX, SOXL, MU, KORU, CL, SKHY, BLESS, SPCX** — токенизированные акции и
товары (SanDisk, SK Hynix, полупроводниковый ETF, Micron, нефть). У SNDK оборот
4,13 млрд — больше, чем у любой крипты, кроме BTC и ETH.

§5 называет XAU, XAG, PAXG, но это **примеры**, а не исчерпывающий список: за время,
прошедшее с написания документа, Binance добавил 131 EQUITY и 8 COMMODITY. Обоснование
§5 («микроструктурные предпосылки метода для них не выполняются») к акциям применимо
тем более, чем к золоту.

Подбирать по тикерам вручную — это ровно тот приём, который §4.1 запрещает.
У биржи есть механический признак.

## Механический признак не-крипто

`/fapi/v1/exchangeInfo`, поля `underlyingType` и `contractType`. Замер по 852 символам:

| underlyingType | сколько |
|---|---|
| COIN | 698 |
| EQUITY | 131 |
| COMMODITY | 8 |
| HK_EQUITY | 7 |
| INDEX | 3 |
| KR_EQUITY | 3 |
| PREMARKET | 2 |

У всех не-крипто `contractType = TRADIFI_PERPETUAL` против `PERPETUAL` у крипты.

Правило в коде: `underlyingType == "COIN" and contractType == "PERPETUAL"`.
Отсекло 156 символов.

**⚠ PAXG этим признаком НЕ отсекается** — у него `underlyingType=COIN`,
`underlyingSubType=RWA`, `contractType=PERPETUAL`, то есть для биржи это обычный
крипто-токен. §5 называет его дословно, поэтому он исключён явным списком.
Механический признак и явный список нужны **оба**; ни один не покрывает другой.

## Опровергнутое ожидание: символ RES не опознаётся

В корпусе есть prizrak_res.txt / `.segments.jsonl`. Опознать монету нечем:

- `manifest.jsonl` хранит только имя исходника `37627648-CwU1oJ1HmYUI3-_N.mp4`;
- расшифровка слышит «монетке, RSI» — это не тикер;
- в транскрипте единственное число «3.0», сверить уровни не с чем.

На бирже есть `RESOLVUSDT`, и слаг `prizrak_res` на него похож — но слаг присвоен
агентом старого репозитория, а это по §0 не референт. **Догадка в код не пошла.**
RES из вселенной исключён, вопрос владельцу открыт.

## Что осталось непроверенным

- Оборот — снимок за одни сутки. Топ-12 через неделю будет другим; набор закреплён
  умышленно (§5) и сам не пересчитывается.
- Качество символов из топа не оценивалось: BLESS, 1000RATS, BICO — новые листинги с
  большим оборотом и короткой историей. Для §2.1 (накопление с 4+ точками границ на
  своём ТФ) короткой истории может не хватить; это выяснится на этапе 3.
- Классификация `underlyingType` взята у биржи как есть и не перепроверялась.
