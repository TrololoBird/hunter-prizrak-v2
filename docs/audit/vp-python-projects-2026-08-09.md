## Сводка по трём открытым вопросам

### 1. Число строк по умолчанию

Распределение среди тех, у кого умолчание вообще есть:
* фиксированный ШАГ ЦЕНЫ, а не число строк: P1 (0.05), P2 (0.25), P9 (по инструменту), P13 (4 тика/строка), P5 (шаг обязателен) — **5 проектов**;
* фиксированное ЧИСЛО строк: P3 — 100, P4 — 50, P6 — 20, P7 — 50, P12 — 24 — **5 проектов, пять РАЗНЫХ чисел**.

**Консенсуса "24" в выборке нет.** 24 встретилось ровно один раз — у КОММЬЮНИТИ-скрипта
ApexFlow (P12), не у TradingView. Единственное свидетельство о живом умолчании самого TV
остаётся Trader Dale: "By default, it is about 100".

Наш код: `build()` — тиковые бины (сторона "фиксированный шаг", как у половины выборки и
самых звёздных P1/P2); `build_tv(rows=...)` — параметр без умолчания. **Отказ зашивать 24 —
подтверждён выборкой**: пять проектов дали пять разных чисел, значение снимается с живого TV.

> ⚠ **ПОПРАВКА 2026-08-24:** хвост «значение снимается с живого TV» отозван — см. поправку
> к пункту 5 ниже. Отказ зашивать 24 выборкой подтверждён и остаётся в силе.

### 2. Цена строки

* НИЗ строки: P3, P4 (границы), P5 — Pine-школа;
* ЦЕНТР: P2; P4 рисует линию ПОК по центру строки; наш замер E-070 — центр лучше сходится с тиковым ПОК;
* "уровень = сама цена" (шаг 1 тик, вопрос вырождается): P1, P9, P10.

**Школы расходятся; большинства нет.** Наш `build_tv` (центр) согласуется с P2 и с тем, как
P4 рисует линию ПОК; Pine-скрипты чаще оперируют нижним краем в геометрии, но ЛИНИЮ ПОК
кладут в середину. Для `build()` вопрос закрыт краями бина (VAH = верхний край верхнего
бина — правка 2026-08-07).

### 3. Алгоритм Value Area

* ОДИНОЧНОЕ расширение (по одной строке, большая сторона, 70%): P1, P3, P4, P8, P9, P10 — **6 из 6 реализаций, где алгоритм виден**;
* ПАРНЫЙ CBOT: в выборке НЕ РЕАЛИЗОВАН НИКЕМ; описан только текстом у LuxAlgo и eminimind.

**Единогласие: одиночное расширение.** Наши `build()` (SINGLE по умолчанию) и `build_tv` —
с большинством; наш `PAIRS` — режим без единого работающего собрата в выборке.

Внутри одиночной школы два разночтения, и здесь выборка раскололась:
* **перевалившая строка**: ДОБАВЛЯЕТСЯ у P1, P4 (`while covered < target: add`), НЕ добавляется у P3 и у справки TV. Наш `build_tv` — не добавляет (как TV), наш `build()` — добавляет (как P1/P4). Расхождение осознанное: build_tv копирует справку TV дословно;
* **ничья сторон**: P3 — `>=` в пользу нижней; P4 — `>=` в пользу верхней; TV — ближняя к ПОК, затем верхняя. Наш `build()` — `>=` в пользу верхней (как P4), `build_tv` — по TV.

### Ничья ПОК (бонус)

Никто из выборки не возвращает отказ: P1/P9 берут максимум, БЛИЖАЙШИЙ К СЕРЕДИНЕ диапазона
(`midmax_idx`); P3 — нижнюю строку; P4 — первую встреченную. Наш `NotReady` — строже всех
(ничья объявляется, а не глотается); если владельцу понадобится тай-брейк для сходимости с TV,
прецеденты: середина диапазона (P1) либо крайняя строка (P3/P4).

### Раскладка объёма

* close-в-бин: P1, P2 (+P6 по колонке price) — Python-школа на дневках;
* размазывание по [low, high] бара: P3 (пропорционально перекрытию), P4 (равномерно), P5 (веса), P12 — Pine-школа;
* по сделкам/тикам: в выборке НИ ОДНОГО (только intrabar-приближение у P4).

Наш профиль по СДЕЛКАМ точнее любого проекта выборки; это расхождение уже заявлено в
докстроке `build_tv` как осознанное.

## Вопрос "24 строки" — что найдено

1. Официальная справка TV (S2 индикатор, S3 инструмент рисования) умолчание **не называет**
   — перепроверено поиском; страницы описывают только формулу Ticks Per Row и пример "25 тиков".
2. Единственный найденный текст с "default 24" — **коммьюнити-скрипт** ApexFlow: "Rows: price
   bucket resolution (10–100, default 24)" — https://www.tradingview.com/script/MKcYFqdB-Fixed-Range-Volume-Profile-ApexFlow/ .
   Это НЕ официальный инструмент; вероятный источник фольклора "24".
3. Живой TV: Trader Dale (02.2026): "By default, it is about 100" —
   https://www.trader-dale.com/how-to-set-up-volume-profile-in-tradingview-5th-feb-26/ ;
   financialtechwiz (2026) умолчаний не называет, рекомендует 100–200.
4. Реимплементации "как TV": MarcosACH — default 100; ApexFlow — 24; mervinj3546 — 50.
5. Различие индикатор/инструмент рисования по умолчанию Row Size из открытых источников
   НЕ извлекается — обе официальные страницы молчат. Закрывается только живым TV владельца.
