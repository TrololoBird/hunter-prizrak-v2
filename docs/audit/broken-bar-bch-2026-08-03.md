# Битый бар в данных биржи — замер 2026-08-03

Найдено валидатором модели `Bar` при переходе на pydantic (FOUNDATION.md §10.1).
До перехода этот бар молча проходил в систему.

## Что нашлось

`BCH/USDT:USDT`, недельный бар от 2020-01-13, как его отдаёт Binance:

```
o=339.65  h=215.69  l=182.65  c=339.62  v=975 831
```

**Максимум ниже открытия.** Такой свечи не существует: high обязан накрывать open и close
по определению. Это не редкий рынок, а битые данные.

## Это не ccxt — врёт сама биржа

Сырой запрос, без ccxt:

```bash
uv run python -c "
import json, urllib.request as u, datetime as dt
url='https://fapi.binance.com/fapi/v1/klines?symbol=BCHUSDT&interval=1w&startTime=1578268800000&endTime=1580083200000'
with u.urlopen(url) as r: d=json.load(r)
for k in d:
    t=dt.datetime.fromtimestamp(k[0]/1000, dt.UTC)
    print(f'{t:%Y-%m-%d} o={k[1]} h={k[2]} l={k[3]} c={k[4]}')
"
```

Ответ содержит тот же бар. Соседние недели корректны.

## Чему бар обязан был равняться

Дневные бары той же недели (13–19 января 2020):

| дата | open | high | low | close |
|---|---|---|---|---|
| 01-13 | 270.83 | 273.00 | 260.76 | 267.00 |
| 01-14 | 267.09 | 370.00 | 267.09 | 348.76 |
| 01-15 | 348.55 | 362.76 | 312.50 | 340.30 |
| 01-16 | 340.36 | 343.44 | 310.20 | 326.77 |
| 01-17 | 326.77 | 384.17 | 320.00 | 368.20 |
| 01-18 | 368.18 | 408.37 | 330.46 | 339.63 |
| 01-19 | 339.65 | 366.59 | 320.15 | 339.62 |

Правильный недельный бар: **o=270.83 h=408.37 l=260.76 c=339.62**.

Биржа отдала `o=339.65` (открытие ПОСЛЕДНЕГО дня недели вместо первого), а `h=215.69` и
`l=182.65` не соответствуют ни одному дню этой недели вообще.

## Почему это важно, а не курьёз

Лой 182.65 на недельном ТФ — это ровно тот материал, из которого §2.1 строит границы
накопления, а §2.2 — уровень BUY. Система нарисовала бы на BCH недельный уровень
поддержки, которого никогда не было, и предъявила бы его оператору как факт.

Один такой бар на 73 828 проверенных (0.0014%). Редкость делает его опаснее, а не
безопаснее: он не заметен ни в какой сводной статистике.

## Как обрабатывается

Не падаем и не молчим (§4.3):

1. Бар отклоняется, в лог уходит `бар отклонён как битый` с исходными числами.
2. Отклонённые бары считаются и печатаются в приёмке отдельной строкой.
3. Возникший разрыв ряда печатается как разрыв — данных за эту неделю у нас правда нет.
4. Разрыв, объяснённый отклонённым баром, не засчитывается в нарушения приёмки:
   это дефект биржи, а не наш. Необъяснённый — засчитывается.

## Команда воспроизведения

```bash
uv run python -m hunter run --symbols 27 --seconds 60 --seed-limit 500
```

В разделе 3 сводки: `баров ОТКЛОНЕНО как битые: 1`.

## Что осталось непроверенным

- Проверены 27 символов × 6 ТФ × 500 баров = 73 828 баров на дату замера. Более глубокая
  история (архив с 2019 года) на битые бары не проверялась.
- Причина дефекта на стороне Binance неизвестна. Обращения в поддержку не было.
- Проверяется только внутренняя согласованность бара (high/low накрывают open/close).
  Бар, у которого все четыре числа согласованы, но неверны, так не поймать.
