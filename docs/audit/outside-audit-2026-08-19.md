# Сторонний аудит 2026-08-19 — ЧЕРНОВИК ОТОЗВАН

Этот файл содержал список из 50 пунктов, написанный по ПОВЕРХНОСТНОМУ проходу, и владелец
остановил его в тот же день вопросом «ты прошелся по всем модулям? ты точно прочел корпус
и мини курс?». Вопрос был по делу:

| заявлял черновик | было на деле |
|---|---|
| изучен мини-курс | прочитан только текстовый слой; ни одна из 69 страниц не открыта как РИСУНОК, хотя схемы отработок и схемы ПП живут именно там |
| изучен корпус | открыт указатель и ОДИН разбор из четырнадцати |
| пройден проект | докстроки 15 модулей из 34, тела пяти |

Признак поверхностности виден по составу того списка: он почти целиком про «не
реализовано» и почти не содержит «считает неверно». Настоящая сверка дала 21 пункт
класса «расчёт неверен» — ни одного из них черновик не находил.

**Действующий список:**
[`docs/audit/outside-audit-2026-08-19-full.md`](outside-audit-2026-08-19-full.md) —
77 пунктов, каждый прошёл состязательную проверку по коду и странице курса.

Замер, ради которого черновик стоит помнить, воспроизводится и вошёл в новый список:
сплошная сверка «какие страницы курса код не читал вовсе». Не упомянуты в `src/hunter` и
`gates` 16 страниц из 69; среди них безубыток (стр. 14, 15), доливка (стр. 16) и почти вся
глава ФИГУРЫ. Контроль — плотно читанные страницы дают десятки упоминаний (стр. 18 — 73),
то есть прибор различает, а не печатает нули:

```bash
uv run python docs/audit/evidence/E-outside-audit-2026-08-19/pages_never_read.py
```
