# Профиль объёма: ПОК и область стоимости — 2026-08-03

Этап 2, начало. FOUNDATION.md §2.2 («Уровень BUY/SELL = ПОК накопления»), §5.

## Что взято готовым, с источником

**ПОК** — «the price of the peak cleared volume is identified as the Point of Control»,
<https://en.wikipedia.org/wiki/Market_profile>.

**Область стоимости** — «the central seventy percent of trading activity about POC
(+/- one standard deviation)», там же. Доля **0.70** каноническая, не подбирается.

**Метод расширения** — здесь источники расходятся, см. ниже.

## Опровергнутое ожидание №2 (моя ошибка по §0)

В первой редакции этого файла процедура «парами» была приписана «Steidlmayer, CBOT,
1980-е». **Такой страницы я не открывал** — формулировка пришла из сводки поисковой
выдачи, а это по §0 не референт, а «рассуждение агента». Ссылка исправлена на
страницы, которые реально прочитаны, и баланс свидетельств оказался ОБРАТНЫМ выбору
по умолчанию:

| процедура | прочитанные источники | тип источника |
|---|---|---|
| **по одному уровню** | CQG (help.cqg.com, Market Profile Value Areas); TradingView (support/solutions/43000713306, TPO indicator) | документация двух независимых вендоров |
| **парами** | eminimind.com, The Ultimate Guide to Market Profile | образовательный сайт, один |
| — | Wikipedia, Market profile | даёт долю 70% и ПОК, процедуру НЕ задаёт |

**CME Group** — институциональный первоисточник: ему принадлежит CBOT, где Стейдлмайер
создал метод в 1980-х, и «Market Profile» является его товарным знаком. Его страница
`cmegroup.com/education/courses/market-profile/understanding-value-area.html`
**недоступна отсюда**: два запроса завершились `ECONNRESET`. Источником не является.

Выбор **заявлен как решение, а не выведен**: по умолчанию реализован парный вариант
(классическое изложение метода), одиночный доступен как `Expansion.SINGLE`, разница
**замерена**. ⚠ Владелец может обоснованно предпочесть одиночный: у него два независимых
вендорских источника против одного образовательного. Численно это меняет границы на
0.0022% (см. ниже).

## Замер разницы

Настоящие сутки BTCUSDT, 2026-08-01, из архива с проверенной контрольной суммой:
399 219 сделок, 8 975 бинов по `tickSize = 0.10`, суммарный объём 54 738.142.

**ПОК: бин 624500, цена 62450.00, объём 685.391** — одинаков для обоих вариантов.

| вариант | VAL | VAH | ширина, бинов | покрыто объёма |
|---|---|---|---|---|
| парами | 62228.80 | 62970.80 | 7421 | 70.0095% |
| по одному | 62230.20 | 62972.20 | 7421 | 70.0323% |

**Разница: 1.40 в цене на каждой границе — 0.0022% от цены ПОК. Ширина области

То есть выбор процедуры на этих данных смещает границы на 14 тиков и не меняет ширину.
Число мало, но оно **измерено**, а не объявлено малым.

## Приёмка §2 в части профиля

| требование владельца | как выполнено |
|---|---|
| каждая величина имеет источник | ПОК и 70% — Wikipedia/Market profile; расширение — CQG + TradingView (по одному) против eminimind (парами), расхождение показано и замерено |
| ПОК не зависит от того, через какую функцию посчитан | ПОК считает **одна** функция `point_of_control`; `build` вызывает её же, своей копии логики нет |
| пустая зона → `NotReady`, а не ноль | проверено: пустая гистограмма даёт «профиль пуст, сделок нет» |
| бин привязан к `tickSize` | бин = `цена // tickSize`, фиксированного числа бинов нет |
| окно профиля не отдельная константа | модуль считает по поданной гистограмме; какие бары входят — определит §2.1 на этапе 3 |
| нет метрик устойчивости/качества | в модуле нет ни одного поля с суффиксом `_score`, `_confidence`, `_quality`, `_strength`, `_pressure`, `_bias` |

Отдельно: **ничья при определении ПОК даёт `NotReady`**, а не «берём первый». Два бина
с равным максимальным объёмом — это настоящая неоднозначность, и выбирать за неё
молча нельзя (§4.3).

## Что осталось непроверенным

- Замер разницы вариантов — **одни сутки, один символ**. На узком профиле с малым
  числом бинов расхождение может оказаться относительно большим.
- **Детекция свингов не реализована.** Единого канона нет, есть конвенции (фрактал
  Билла Вильямса, ZigZag с порогом); выбор конвенции и её источник — следующая работа.
- Профиль считается по гистограмме, накопленной из aggTrade. Совпадает ли он с
  профилем, который рисует торговый терминал автора, **не проверялось** — для этого
  нужен этап 3 и границы зоны.
- Ничья ПОК на живых данных не наблюдалась ни разу; ветка проверена только
  синтетически (пустая гистограмма — на настоящей).
- **Первоисточник процедуры расширения не получен.** CME недоступен отсюда, книг
  Стейдлмайера в проекте нет. Все имеющиеся ссылки — вторичные: два вендора и один
  образовательный сайт. Если владелец получит доступ к CME или к книге, выбор
  варианта надо пересмотреть по ним.
