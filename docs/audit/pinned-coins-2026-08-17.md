# Какие монеты закрепить: замер по каналу автора, TradingView и корпусу

**Дата:** 2026-08-17. **Повод:** поручение владельца — «изучи youtube канал prizzrak и
tradingview и найди монеты самостоятельно», то есть выбрать состав `pinned` в
[`config/bot.toml`](../../config/bot.toml) замером, а не спросив.

**Результат:** `pinned = BTC, ETH, BCH, POL`.

⚠ Замер отвечает на вопрос «о чём автор говорит», а НЕ на вопрос «что выгодно торговать».
Второго он не касается вовсе, и выводить его отсюда нельзя.

---

## 1. Три независимые выборки

Одна выборка ответа не даёт: канал за сутки выпускает 4-5 роликов, и что попало в любую
одну из них, зависит от дня. Поэтому взяты три источника разной природы.

| выборка | что это | объём | окно |
|---|---|---|---|
| корпус | расшифрованные видео в репозитории, `research/prizrak_corpus/INDEX.md` | 14 роликов | июль 2026 |
| RSS канала | `youtube.com/feeds/videos.xml?channel_id=UC3a2K5AaJ1S2ms-y1DLsJ5w` | 15 роликов | 13-16 августа 2026 |
| TradingView | `ru.tradingview.com/ideas/prizraktrade`, 3 страницы | 53 идеи | без дат на странице |

**Канал опознан, а не предположен.** Слаг `prizrak_*` в корпусе referent'ом не является
(§0), поэтому канал найден по единственной ссылке в манифесте корпуса —
`https://youtu.be/7ew29d1jY6s`. Страница видео называет канал: **Prizrak_Trade**,
`@Prizrak_Trade`, `UC3a2K5AaJ1S2ms-y1DLsJ5w`, 3,63 тыс. подписчиков, **1 тыс. видео**,
описание — «прогнозы рынка криптовалют, разбор рабочих стратегий трейдинга, наш личный
опыт какие монеты покупать и где продавать».

⚠ **Ограничение выборки RSS, и оно жёсткое:** лента отдаёт только 15 последних роликов из
тысячи. Список видео на самой странице канала подгружается скриптом и в непоказанном окне
браузера не подгрузился — то есть окно «13-16 августа» это не выбор, а всё, что удалось
прочитать. Вывод о РЕДКИХ монетах из такой выборки делать нельзя; вывод о ПОСТОЯННЫХ —
можно, и именно он ниже.

| тикер | выходов | выборок | во вселенной | оборот 24ч, $ | карта в леджере |
|---|---|---|---|---|---|
| BTC | 10 | 2 | да | 3 477 539 744 | 69 активных зон |
| ETH | 3 | 1 | да | 2 858 580 679 | 47 |
| THETA | 2 | 2 | да | 1 167 262 | **нет** |

| остальные 70 | по 1 | 1 | 17 из 70 | от 0 до 715 млн | 6 из 70 |

**BTC — единственная монета, к которой автор возвращается постоянно:** 5 из 15 последних
роликов канала (13-16 августа) и 5 выходов в корпусе, включая два совместных разбора с ETH
по 47 и 54 минуты. Всё остальное — ротация: монета выходит один раз и уступает место
следующей. Ровно это ротационное поведение и обслуживает ответ бота по запросу, а
закреплённый список обязан быть постоянной частью, а не ротацией.

## 3. Контроль: 16% упомянутого автором сегодня не торгуется

Проверка выборки на бирже — это и есть её контроль. Если бы список был случайным набором
тикеров, он не отличался бы от списка автора; если бы он был свежим — торговалось бы всё.

| | |
|---|---|
| тикеров всего | 75 |
| нет рынка на `binanceusdm` | 4 (ACA, APEX, FOXY, PYR) |
| рынок есть, НЕ торгуется | 8 (FTM, MKR, TON, RDNT, NFP, HFT, DEGEN, TROY) |
| во вселенной `config/universe.toml` | 20 |

**Двенадцать из 75 (16%) сегодня недоступны, и все двенадцать пришли из TradingView.**
Это и есть свидетельство природы той выборки: идеи TradingView — разовые сделки прошлого,
а не наблюдаемый список. Закреплять их нельзя было бы, даже если бы захотелось.

⚠ **Собственная ошибка первого прогона, исправлена.** `SHIB` и `TON` были объявлены
отсутствующими: на этой площадке монета называется `1000SHIB`, а `TON` автор в ролике
2026-08-14 сам называет `#GRAM (#TON)`. После правки `SHIB` нашёлся торгуемым; `TON` —
нет, и торгуемого рынка с именем, содержащим `TON`, на площадке нет. Ищутся такие случаи
поиском по подстроке имени, а не глазами.

## 4. Второе условие: у монеты обязана быть карта

Публикация раз в 4 часа по монете без карты печатала бы в канал отказ. Обзор карты:

```bash
uv run python -c "
from hunter import store
c = store.open_readonly()
for r in c.execute(\"SELECT symbol, COUNT(*), SUM(state='active'), MAX(last_seen)\"
                   ' FROM levels GROUP BY symbol ORDER BY 2 DESC'):
    print(r)
c.close()"
```

Карта есть у **11 символов из 27 вселенной**: BTC 69 активных зон, ETH 47, BCH 25, POL 23,
ASTR 17, ONDO 14, ANKR 13, AEVO 11 — плюс три символа ВНЕ вселенной (см. раздел 6).
THETA и SOL карты не имеют вовсе: служба гонялась по первым девяти символам.

Пересечение двух условий (постоянный разбор ∧ есть карта) и даёт ответ:

```toml
pinned = ["BTC/USDT:USDT", "ETH/USDT:USDT", "BCH/USDT:USDT", "POL/USDT:USDT"]
```

THETA — единственный альт с двумя независимыми выборками — НЕ закреплён: карты нет.
Появится после прогона службы по всей вселенной, и тогда решение стоит пересмотреть.

## 5. Команда воспроизведения замера

Таблицы выборок (кто где встретился) вписаны в зонд как данные — они сняты чтением
источников, а не вычислены. Зонд отвечает на один вопрос и здесь же сохранён (§7.4):

```bash
uv run python -c "
import asyncio, ccxt.async_support as ccxt
from hunter.config import load_universe
CORPUS = {'BTC':5,'ETH':3,'BCH':1,'POL':1,'ONDO':1,'AEVO':1,'ASTR':1,'ANKR':1,'ARPA':1,
          'UNI':1,'SAND':1,'CFX':1,'STX':1,'CHZ':1,'THETA':1,'SUPER':1,'NEO':1}
RSS = {'BTC':5,'DUSK':1,'APEX':1,'LINK':1,'SOL':1,'RESOLV':1,'THETA':1,'SHIB':1,'TON':1,'SEI':1}
ALIAS = {'RATS':'1000RATS','FLOKI':'1000FLOKI','BABYDOGE':'1MBABYDOGE','SHIB':'1000SHIB'}
async def main():
    uni = load_universe(); ex = ccxt.binanceusdm({'enableRateLimit': True})
    try: markets = await ex.load_markets(); tick = await ex.fetch_tickers()
    finally: await ex.close()
    for base in sorted({*CORPUS, *RSS}, key=lambda b: -(CORPUS.get(b,0)+RSS.get(b,0))):
        sym = f\"{ALIAS.get(base, base)}/USDT:USDT\"; mk = markets.get(sym)
        print(f'{base:8} выходов {CORPUS.get(base,0)+RSS.get(base,0):3}',
              'торгуется' if mk and mk.get('active') else 'НЕ ТОРГУЕТСЯ',
              'вселенная' if sym in uni.symbols else '—',
              f\"{float((tick.get(sym) or {}).get('quoteVolume') or 0):,.0f}\")
asyncio.run(main())"
```

Полная выборка TradingView (53 идеи) в эту команду не входит: она прочитана со страниц
`ru.tradingview.com/ideas/prizraktrade/`, `.../page-2/`, `.../page-3/` и в замере
участвует только третьим голосом — ни одна монета не попала в закреплённые по ней одной.

## 6. Что найдено попутно и НЕ исправлено

**1. В боевом леджере лежат символы вне вселенной, включая прямо запрещённый §5 — и это
портило число, которое печаталось владельцу.**

Карта содержит `BTW/USDT:USDT` (753 строки, 89 активных — больше, чем у BTC),
`BEAT/USDT:USDT` (60) и **`XAU/USDT:USDT` (34 строки, 13 активных)**. XAU — золото,
FOUNDATION §5 называет его дословно в списке исключённых.

Хуже, чем лишние строки в карте: **те же символы есть в ЖУРНАЛЕ СИГНАЛОВ — 49 из 192
(25.5%)**, а запрос владельца «результат в R (стр. 9 курса)» считает по всей таблице
исходов. То есть средний R печатался вместе с золотом, и узнать об этом по выдаче было
нельзя. Ровно тот класс, который CLAUDE.md называет главным: «всякая накопленная
статистика обязана называть, по какой ПОДВЫБОРКЕ она посчитана».

**Что сделано:** `hunter ledger` теперь сверяет состав журнала со вселенной, печатает
числа и **падает кодом 1**, если в журнале есть посторонние символы
(`__main__._journal_vs_universe`).

**Контроль прибора** (способен ли он ответить иначе): та же команда с вселенной, в
которую эти три символа добавлены, печатает «вне вселенной: 0» вместе со знаменателем
(«сверено 11 символов со списком из 30») и возвращает 0. На пустом леджере — тоже 0, то
есть шаг CI не краснеет.

```bash
uv run python -m hunter ledger ; echo "код: $?"
```

**Строки НЕ удалены.** Журнал боевой, удаление необратимо, и выбор — включить эти символы
во вселенную или убрать их сигналы — принадлежит владельцу. Код сам не делает ни того,
ни другого; он делает смесь видимой.

**2. Открытый вопрос про `RES` получил внешнее свидетельство.** `config/universe.toml`
держит символ `RES` исключённым: корпус содержит `prizrak_res`, опознать монету было
нечем, а `RESOLV` считался догадкой (§0). Канал 2026-08-15 выпустил ролик
**«#RESOLV: ПЕРВЫЙ ЛОНГ В ПЛЮСЕ»**, и `RESOLV/USDT:USDT` торгуется на площадке
(оборот 1,1 млн). Это не доказывает, что июльский ролик был о RESOLV, — но снимает
возражение «такой монеты автор не разбирает». Решение о включении в §5 — владельца.

**3. Автор торгует монеты, которых нет во вселенной.** Из 15 последних роликов канала
вне вселенной: LINK (оборот 132 млн), SEI (5,2 млн), DUSK (12,1 млн), RESOLV (1,1 млн),
APEX и SHIB. Бот ответит по ним сборкой по запросу (~345 с), но постоянно за ними никто
не следит. Расширение вселенной — решение владельца по §5.
