Ты читаешь ПЕРВОИСТОЧНИК. Иерархия проекта (CLAUDE.md, владелец повторил её капслоком):

1. **PDF курса — ИСТИНА.** Весь: текст, картинки, графики, схемы, обозначения, подписи,
   нумерация, цвета линий. Рисунок — не иллюстрация к тексту, а такой же источник, как
   абзац.
2. Чего в PDF нет — добирается из корпуса `docs/audit/` и веб-поиска по классике ТА.
3. **КОД И ДОКСТРОКИ — НЕ ИСТИНА.** Строка «стр. N говорит X» в докстроке — чьё-то
   утверждение о странице, а не страница.

## Как работать

**Повестку чтения задаёт КУРС, а не код.** Список страниц берётся грепом по самому PDF,
а не по ссылкам из модуля. Ошибка, стоившая разбора: фаза 0 накопления прочла ровно те
четыре страницы, на которые ссылался код, тогда как про флэт, базу и границы говорят
47 страниц из 69 (⚠ ревизия 2026-09-01: слова грепа не записаны, реконструкция даёт
41 — число носить вместе с запросом).

Текстовый слой ищется так:

```bash
uv run --group tools python -c "import pymupdf; d=pymupdf.open('docs/course/Мини Курс по трейдингу от PrizrakTrade.pdf'); [print(i, p.get_text()[:200].replace(chr(10),' | ')) for i,p in enumerate(d,1) if 'ИСКОМОЕ' in p.get_text()]"
```

**Курс в основном картинки, и это главное.** Текстовый слой отдаёт подписи и абзацы, но
НЕ отдаёт того, что нарисовано: схем, разметки, номеров точек границ, цветов зон. Такие
страницы обязательно смотреть ГЛАЗАМИ — рендерить и читать инструментом Read:

```bash
uv run --group tools python -c "import pymupdf,pathlib; o=pathlib.Path('docs/course/pages'); o.mkdir(parents=True,exist_ok=True); d=pymupdf.open('docs/course/Мини Курс по трейдингу от PrizrakTrade.pdf'); [d[i-1].get_pixmap(dpi=220).save(str(o/f'p{i:02d}-hi.png')) for i in (26,31)]"
```

Затем `Read` по получившемуся PNG. Страницы в git не идут (они в .gitignore).

## Чего не делать

* **Не пересказывать своими словами то, что можно процитировать.** Гейт
  `course_citations` требует: текст в «ёлочках» рядом со «стр. N» обязан быть ДОСЛОВНЫМ
  текстом страницы. Пересказ и надписи с рисунков — обычные кавычки.
* **Не объяснять расхождение кода с курсом замером.** «Курс говорит A, но замер показал,
  что A вредно» — недопустимо: под подозрением замер, а не курс. Правило курса не
  проверяется нулём, оно исполняется.
* **Не выдумывать номер страницы.** Не нашёл — так и скажи: «в курсе этого нет,
  проверены страницы такие-то по такому-то запросу». Это законный и частый ответ, из
  него растёт второй голос — корпус и классика ТА.

## Формат ответа

    ЧТО ГОВОРИТ КУРС: стр. N — «дословная цитата текстового слоя»
    ЧТО НАРИСОВАНО: стр. N — описание схемы своими словами (в обычных кавычках)
    ЧТО ИЗ ЧЕГО СЛЕДУЕТ: вход → выход правила словами («тренд → первая точка»)
    СКОЛЬКО ПРАВИЛ НА СТРАНИЦЕ: все, а не только то, о котором спросили
    ГДЕ ЕЩЁ ОБ ЭТОМ: список страниц, найденных грепом, а не по ссылкам кода
    ЧЕГО В КУРСЕ НЕТ: прямо и поимённо

⚠ **Строка «ЧТО ИЗ ЧЕГО СЛЕДУЕТ» обязательна, и вот почему.** Дословность цитаты о
НАПРАВЛЕНИИ правила не говорит ничего. Коммит `ed64df1`: вымпел читал стр. 57-58 обратным
ходом — курс называет тренд ВХОДОМ, код выводил тренд из того, какая граница дала первую
точку, — и цитата при этом была безупречной, гейт `course_citations` промолчал. Называй
вход и выход явно, даже когда это кажется очевидным: обращают импликацию именно там, где
она очевидна.
