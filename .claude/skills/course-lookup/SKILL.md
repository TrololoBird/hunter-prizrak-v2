# Чтение курса: текст сначала, рисунок потом

⚠ **Заголовок свода «курс лежит картинками — его надо отрендерить, чтобы прочитать» был
НЕВЕРЕН, исправлено 2026-08-28.** У PDF есть текстовый слой: `page.get_text()` отдаёт
**38 166 знаков по 69 страницам**, и гейт `course_citations` сверяет «ёлочки» посимвольно
именно по нему. Прежняя редакция гнала каждую сессию рендерить 69 картинок ради того, что
достаётся за секунду.

## 1. Текст — первым

Поиск страницы по слову и дословная цитата берутся отсюда. Это же единственный способ
проверить свою цитату так, как её проверит гейт.

```bash
uv run --group tools python -c "import pymupdf; d=pymupdf.open('docs/course/Мини Курс по трейдингу от PrizrakTrade.pdf'); [print(i, p.get_text()[:200].replace(chr(10),' | ')) for i,p in enumerate(d,1) if 'ИСКОМОЕ' in p.get_text()]"
```

## 2. Рендер — только когда нужен РИСУНОК

Схемы, стрелки, нумерация точек, цвета линий в текст не попадают, а по иерархии
источников рисунок — **такой же источник, как абзац**. Страницы уходят в
`docs/course/pages/*.png`, в git НЕ идут, в свежем клоне их нет.

```bash
uv run --group tools python -c "import pymupdf; d=pymupdf.open('docs/course/Мини Курс по трейдингу от PrizrakTrade.pdf'); [p.get_pixmap(dpi=140).save(f'docs/course/pages/p{i:02d}.png') for i,p in enumerate(d,1)]"
```

## 3. Сверить цитату ДО того, как её написать

```bash
uv run --group gates python gates/course_citations.py; echo "код: $?"
```

## Правила ссылки. Нарушал их я сам

**«Ёлочки» рядом со ссылкой «стр. N» означают ДОСЛОВНУЮ цитату страницы.** Свои слова,
пересказ и надписи с рисунков берутся в ОБЫЧНЫЕ кавычки — иначе выдумка выглядит как
проверенная ссылка. 2026-08-18 гейт поймал в `tgbot.py` мою собственную фразу в «ёлочках»
при ссылке на стр. 23.

⚠⚠ **Дословность цитаты НИЧЕГО не говорит о НАПРАВЛЕНИИ правила.** Рядом со ссылкой
обязана стоять строка **«что из чего следует»** — вход и выход правила словами: «тренд →
первая точка», а не «первая точка → тренд».

Заведено по счёту: коммит `ed64df1` — «вымпел читал стр. 57-58 ОБРАТНЫМ ХОДОМ», то есть
курсовое правило было реализовано с обращённой импликацией **при формально безупречной
цитате**, и гейт `course_citations` пропустил это, потому что сверяет буквы, а не логику.
Второй раз правило было исполнено наполовину. Ни один прибор такое не ловит — направление
называет ЧЕЛОВЕЧЕСКАЯ строка рядом с цитатой.

## Три запрета

Каждый нарушен обзором накопления 2026-08-07, разбор —
[`docs/audit/accumulation-projects-2026-08-07.md`](../../../docs/audit/accumulation-projects-2026-08-07.md):

* **правило курса не проверяется нулём, оно исполняется.** Схема стр. 18 нумерует точки
  границ 1–10 строго через сторону; я взял рисунок как гипотезу, построил нуль, мера
  насытилась — и вопрос остался «открытым». Рисунок был истиной: правится КОД. Замер
  вокруг требования курса законен ровно в одном виде — показать ЦЕНУ уже принятой правки;
* **расхождение с курсом не объясняется собственным замером.** «Курс говорит A, но замер
  показал, что A вредно, поэтому оставляем B» — недопустимо. Если замер спорит с курсом,
  под подозрением замер и корпус;
* **повестку чтения задаёт курс, а не код.** Фаза 0 накопления прочла ровно те четыре
  страницы, на которые ссылался модуль, тогда как про флэт, базу, границы и структуру
  говорят **47 страниц из 69**. Список страниц берётся грепом по самому PDF.

## ⚠ И сам вопрос бывает порождением ИИ

Владелец, 2026-08-24: «если их нет, то возможно вопрос на который ты ищешь ответ это
порождение ии». Проверка подтвердила это делом: из семи открытых вопросов метода **один
был выдуман целиком** — «классика определяет зону как ПОК ± σ». Вокруг выдумки успел
вырасти честный замер с подвыборкой, контролем и четырьмя числами: он мерил расстояние до
объекта, которого в методе не существует.

**Проверка источника обязана предшествовать замеру:** сперва цитата из внешнего
источника, потом цифры.
