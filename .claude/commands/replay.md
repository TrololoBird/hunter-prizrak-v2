description: Повтор — та же карточка из тех же кадров, дифф расчёта (§10.6 условие 2)
argument-hint: "[имя прогона, по умолчанию last]"
---

Единственная проверка изменения расчёта, не требующая чтения кода. §10.6 дословно: «на
этих сохранённых данных карточка была такой, стала такой».

```bash
uv run python -m hunter replay --run-id last --diff
```

Как читать результат:

* **«расчёт не изменился»** — правка расчёта не тронула. Это то, чего ждут от правки
  исполнения, транспорта или уборки;
* **«расчёт изменился»** — обязателен разбор построчно. Скажи владельцу не «изменилось у
  3 символов», а ЧТО именно: какие строки исчезли, какие появились, и следует ли это из
  сделанной правки. Дифф, объяснить который нельзя, — это дефект, а не улучшение;
* ⚠ дифф **строго вычитающий** (только удаления и названные причины) — признак того, что
  правка убрала лишнее и не тронула остального. Дифф с изменёнными числами требует
  отдельного объяснения по каждому числу.

Показать карточку целиком: `uv run python -m hunter replay --run-id last --card BTC_USDT_USDT`
