---
description: Повтор — доказать, что карточка ДЕТЕРМИНИРОВАНА: те же кадры дают тот же текст
argument-hint: "[имя прогона, по умолчанию last]"
---

Проверяет ОДНО: воспроизводится ли карточка из сохранённых кадров посимвольно. Пустой
дифф — карточка детерминирована, в неё не просочились множества в случайном порядке,
отметки времени и порядок словарей.

⚠ **Это НЕ проверка изменения расчёта.** Здесь до 2026-08-23 стояло «единственная
проверка изменения расчёта, не требующая чтения кода» (§10.6 условие 2) — отменено
владельцем 2026-08-19: «ты гоняешь скрипты на СТАРЫХ собранных данных и пытаешься
сравнить с тем что было». Кадры недельной давности показывают разницу двух версий кода
на мёртвом рынке, а не поведение системы. **Изменение расчёта предъявляется ДВУМЯ
КАРТОЧКАМИ на свежих данных** (`/batch`), и только так.

```bash
uv run python -m hunter replay --run-id last --diff
```

Как читать результат:

* **«расчёт не изменился»** — правка расчёта не тронула. Это то, чего ждут от правки
  исполнения, транспорта или уборки;
* **«расчёт изменился»** — обязателен разбор построчно. Скажи владельцу не «изменилось у
  3 символов», а ЧТО именно: какие строки исчезли, какие появились, и следует ли это из
  сделанной правки. Дифф, объяснить который нельзя, — это дефект, а не улучшение;
* ⚠ дифф **строго вычитающий** (только удаления и названные причины) — признак того, что
  правка убрала лишнее и не тронула остального. Дифф с изменёнными числами требует
  отдельного объяснения по каждому числу.

Показать карточку целиком: `uv run python -m hunter replay --run-id last --card BTC_USDT_USDT`
