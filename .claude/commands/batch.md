Пакетный прогон: собирает окно, считает один раз, выходит. Для наблюдения без остановки
есть `/serve`.

```bash
uv run python -m hunter run --symbols 3 --seconds 60 --horizon-days 5 --run-id last
```

Аргументы владельца, если заданы, подставь вместо `--symbols` и `--seconds`.

После прогона:

1. приведи **число нарушений приёмки** и, если оно не ноль, разбери каждое — но сначала
   проверь, не артефакт ли это. ⚠ Свежесть судится на момент СНЯТИЯ снимка; прогон,
   начавшийся за секунды до границы ТФ, законно показывает отставание, которое
   догоняющий опрос закроет сам;
2. назови, сколько сигналов эмитировано и сколько уровней система торговать отказалась —
   и по какой причине курса;
3. предложи `/replay`, если расчёт менялся: §10.6 требует предъявлять изменение диффом
   повтора, а не словами.
