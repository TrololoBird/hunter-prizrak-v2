⚠⚠ **ЭТО ПОЛОВИНА, А НЕ СИСТЕМА. Для боевого запуска нужен `/live`.**

Служба считает и пишет леджер, но НИЧЕГО не доставляет: канал будет молчать. Владелец
назвал раздельный запуск абсурдом (2026-08-28, дословно: «зачем нам бот без серва? или
серв без бота? ЭТо абсурд!»), и эта команда осталась только для отладки самого расчёта,
когда доставка мешает.

Боевое исполнение (§8, находка А-1): сбор идёт непрерывно, расчёт — циклами в рабочем
потоке, карточка и леджер из одного расчёта.

```bash
uv run python -m hunter serve --symbols 3 --cycles 3 --cycle-seconds 300 --horizon-days 5 --run-id serve
```

* `--cycles 0` — работать до сигнала остановки (Ctrl+C). Тогда запускай в фоне, иначе
  сессия встанет;
* такт 300 с выведен из младшего ТФ проекта: чаще пересчитывать нечего, новых закрытых
  баров между циклами не появится.

Служба останавливается по Ctrl+C **дорабатывая текущий цикл** — кадры и карточка
останутся от одного момента. Не убивай процесс силой: прерванный на середине расчёт
ломает повтор §10.6.

После остановки доложи: сколько циклов, сколько с нарушениями, наибольшая задержка цикла
событий, сколько сделок потеряно потоком, поднимались ли задачи наблюдения.
