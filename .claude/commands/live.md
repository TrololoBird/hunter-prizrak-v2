Штатный боевой запуск. Обе половины в ОДНОМ процессе: служба считает и пишет леджер,
бот из него доставляет в канал.

```bash
uv run python -m hunter live
```

⚠ **Это единственная команда, которой поднимают систему.** `/serve` и `bot` — половины,
и по отдельности они бессмысленны: служба без бота нема, а бот без службы сутками шлёт
уведомления по СТАРОЙ карте и молчит о том, что расчёт стоит. Заведено 2026-08-28 по
возражению владельца, дословно: «зачем нам бот без серва? или серв без бота? ЭТо абсурд!»

Полезные ключи:

* `--symbols N` — взять только первые N символов вселенной (для короткой проверки);
* `--cycles N` — остановиться после N циклов расчёта; без ключа работает до Ctrl+C;
* `--cycle-seconds` — такт расчёта, по умолчанию 300 с (выведен из младшего ТФ проекта:
  чаще пересчитывать нечего, новых закрытых баров между циклами не появится).

**Половинная жизнь запрещена явно:** если любая из двух задач кончилась — по отказу или
сама, — вторая снимается, печатается `degraded` с именем кончившейся и причиной, и
процесс выходит с кодом 1. Молчаливой работы вполсилы быть не может.

Останавливать Ctrl+C, **дорабатывая текущий цикл**. Не убивать силой: прерванный на
середине расчёт ломает повтор.

После остановки доложить: сколько циклов, сколько с нарушениями приёмки, наибольшая
задержка цикла событий, поднимались ли задачи наблюдения, что ушло в канал (`hunter sent`).
