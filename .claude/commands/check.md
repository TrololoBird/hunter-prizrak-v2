Запусти единую проверку владельца. Если число символов не задано аргументом — возьми 3:
полный прогон идёт минуты и для быстрой проверки не нужен.

⚠ Числа вселенной здесь НЕ называть. Стояло «полная вселенная из 27 символов» — состав,
отменённый дважды (2026-08-18 и 2026-08-21). С приказа владельца 2026-08-21 («всю доску,
696») `symbols` в `config/universe.toml` — это ЯДРО с полной лестницей ТФ, а вселенная
раскрывается живым вызовом биржи до всей доски бессрочных по короткой лестнице. Значит
размер вселенной — величина ПРОГОНА, а не константа файла, и заученное число протухает
молча.

```bash
uv run python -m hunter check --symbols 3 --seconds 120
```

Затем **объясни вердикт человеку, который не программист**:

* если всё хорошо — назови это одной строкой и приведи главные числа: сколько рядов
  проверено, сколько сделок принято, каков сдвиг часов;
* если есть «ПЛОХО» — скажи, что именно сломано и что это значит на практике, а не
  процитируй строку. Отдельно скажи, чинится ли это само (сеть, очередь биржи) или
  требует правки кода;
* ⚠ если какое-то число выглядит подозрительно круглым или нулевым — проверь, способен
  ли прибор выдать иное, прежде чем докладывать его как результат (CLAUDE.md).

Не начинай чинить без команды владельца: сначала вердикт, потом решение.
