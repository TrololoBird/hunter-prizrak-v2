```bash
uv run python -m hunter ledger
```

§10.6 условие 1: владелец проверяет журнал сигналов тремя запросами, не читая код. Команда
сама печатает SQL каждого запроса и в конце доказывает, что соединение открыто **только на
чтение** — пробует записать и показывает отказ СУБД.

При разборе чисел держи в уме и скажи владельцу:

* ⚠ **это журнал, а не бэктест.** Исход считается только по барам, закрывшимся ПОСЛЕ
  записи сигнала. У свежего сигнала исхода нет и быть не может;
* сумма R без знаменателя вводит в заблуждение. Рядом обязаны стоять: сколько эмиссий
  всего, сколько не заполнилось, сколько ещё открыто;
* **комиссии, фандинг и проскальзывание не моделируются нигде.**

База пустая — создать: `uv run python -m hunter ledger --init`
